# TFG: Monitoreo de Radiación Beta-Gamma (IEK)

Este repositorio contiene el código fuente y la documentación del Trabajo de Fin de Grado titulado **[DISEÑO DE UNA RED DE SENSORES MEDIANTE IOT PARA EL MONITOREO DE RADIACION BETA-GAMMA ORIENTADO AL CAMPUS DE LA UNIVERSIDAD NACIONAL DE ASUNCION]**. El sistema realiza la medición, procesamiento y visualización de niveles de radiación Beta y Gamma utilizando un Detector Geiger-Müller y unos ESP32 LoRa, un script de en Python, un sistema de control en Node-RED y visualización en Grafana.

## 📁 Estructura del Proyecto

* **📁 ESP32:** Códigos fuente para el microcontrolador encargados de la lectura de sensores.
* **📁 Python:** Script de automatización y procesamiento de datos.
* **📁 NodeRED:** Flujo en formato JSON para el panel de control visual.
* **📁 Documentacion / imagenes:** Diagramas de flujo, esquemáticos y capturas del sistema.
